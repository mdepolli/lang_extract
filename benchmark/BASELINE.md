# Dialogue Benchmark Baseline — 2026-07-04

Definitive parity run between LangExtract (Elixir) and upstream
[google/langextract](https://github.com/google/langextract) (Python) on the
`dialogue` task, 12 Project Gutenberg documents. This snapshot exists because
`benchmark/results/` is gitignored; it preserves the citable numbers and full
provenance.

## Reading these numbers

- Each library runs its **native wire format**. Upstream's YAML path cannot
  parse Sonnet 5 output (verified broken at v1.6.0), so same-format runs
  would only benchmark that gap.
- claude-sonnet-5 accepts no sampling controls, so **count-level metrics
  (totals, exact/fuzzy splits) are single-run samples** — expect ±1–2%
  between reruns. Conditional metrics (class/status/offset agreement on
  matched pairs) are stable across runs.
- This baseline follows the aligner parity port (upstream v1.6.0 lesser +
  LCS semantics, commit `3d2132f`) and the verbatim prompt instruction
  (`e9b5339`). Before those, the Elixir exact rate was 77.5% with 93
  not-found spans on the same corpus.

To reproduce: `mix benchmark.run --task dialogue` and
`benchmark/.venv/bin/python benchmark/scripts/run_python.py --task dialogue`,
then `benchmark/.venv/bin/python benchmark/scripts/compare.py`.
